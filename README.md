# Old address redirect

The beta used to be at https://dmullan17.github.io/deon-toolkit-beta-v3/. These files go
in a separate **public** repo named `deon-toolkit-beta-v3` (the main repo is renamed and
made private) with GitHub Pages serving its `main` branch. Every old link, including
`#/en/place/…` routes, forwards to the same page on the new address. No toolkit code or
data is in this repo.

If the toolkit's address changes, update `NEW` and the two URLs in `index.html`, then
copy it to `404.html`.
